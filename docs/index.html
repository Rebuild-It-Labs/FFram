Fast FFmpeg Renderer for Audio and Moving-pictures

FFram is a fast, highly interactive Terminal User Interface (TUI) for executing complex media operations on Windows, macOS, and Linux. It abstracts complex FFmpeg command-line syntax into an intuitive menu system with native file picker dialogs, real-time progress bars, and ETA calculations.

Usage Examples

Using FFram is incredibly simple. You can launch the interactive UI from any terminal:

# Launch the main menu
ffram

# Or pass a file directly to skip the initial file picker
ffram -f "C:\path\to\video.mp4"

Once launched, use the fuzzy search or browse categories to select the operation you want to perform.

How to Contribute

We welcome contributions from the community! Here is how you can get involved:

  1. Fork the repository: Click the "Fork" button on our GitHub page.
  2. Clone locally: git clone https://github.com/Rebuild-It-Labs/FFram.git
  3. Install dev dependencies: Set up your environment (we recommend using a virtual environment).
  4. Create a branch: Make your changes on a descriptive branch name.
  5. Submit a Pull Request: Open a PR with a clear description of your improvements or fixes.

Before contributing, please review our CONTRIBUTING.md file for code standards and guidelines.
