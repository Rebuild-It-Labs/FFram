# Installation

## Prerequisites
- Python 3.8+
- FFmpeg installed and available in your system's PATH.

## Install via Pip
The easiest way to install FFram is via pip:
```bash
pip install ffram
```

## Install from Source
To install from source for development:
```bash
git clone https://github.com/Rebuild-It-Labs/FFram.git
cd FFram
pip install -e .
```
