# Quick Start

To launch the FFram interactive CLI, simply run:
```bash
ffram
```

If you want to skip the file selection prompt and directly load a video, use the `-f` flag:
```bash
ffram -f "/path/to/my/video.mp4"
```

## Basic Operations
Once launched, you can navigate the menu using your keyboard arrow keys. Press `Enter` to select a category, and then select the specific operation you want to run.
